How Bolt-3 Compresses & Routes Past Context

STAGE 01 • THE MEMORY BOTTLENECK

Unbounded Softmax KV Grows Linearly Forever

Standard GQA Transformers like Qwen/Qwen3-4B append every new token's Key and Value across all 36 layers. At 65,536 tokens, exact bfloat16 KV caches consume 9,216 MB and memory-bandwidth saturation cuts decode throughput from 59.4 tok/s down to 29.6 tok/s.

KV_Bytes = L(36) * 2 * HKV(8) * HD(128) * T * 2B → 9.22 GB @ 64k
STAGE 02 • SINK + 4C UNIFIED LOCAL RING

Chunked Execution (C = 128, 4C = 512 Ring) & CUDA Graph

Bolt-3.1 processes sequences in C = 128 token chunks. It permanently pins the first n_sinks = 4 tokens plus a unified circular loc_chunks = 4 ring (512 exact local tokens). During single-token decode, _Bolt3GraphRunner writes in-place via index_copy_ with zero allocation.

buf_k = [ sink(4) | ak_eff(128) | loc_ring(512) | (cold) ]
STAGE 03 • TRI-PARTITIONED DIVERSITY ATTRACTORS

Un-Smeared Cosine Merge & Multi-Band Eviction (S = 128)

Evicted local tokens enter S = 128 tri-partitioned slots: S_hh = 48 heavy-hitters, S_land = 48 landmarks, and S_proto = 32 un-smeared high-novelty prototypes (weighted updates stay clean, biased by kappa * log(mass)), cutting 16k/64k KL by 31–36% over local windows alone.

S = S_hh(48) + S_land(48) + S_proto(32)  |  bias = kappa * log(mass)
STAGE 04 • GERSHGORIN M_RES + L_MEM SUPERVISION

Evicted-Mass Supervised Delta Writes into M_res ([HKV, HD, HD])

Overflow tokens from attractors write into a fixed [HKV, HD, HD] float32 matrix with Gershgorin spectral normalization and soft-clipped readout. Step-2 L_mem evicted-mass loss trains beta_proj and eta_proj across all 8 Bolt-3 layers to recover long-range signal past the local window.

M_res ← gamma * M_res + K_ev^T @ ((V - K_ev @ M_res) * beta / gershgorin)
STAGE 05 • OPTION-B SPARSE COLD-ARMED LAYERS

Sparse Mid-Deep Exact Buckets Capped Past 32,768 Tokens

In bolt3.1-qwen3.5-4b.pth, 24 native GatedDeltaNet layers and 5 pure O(1) layers pair with 3 mid-deep Cold-Armed layers ([11, 19, 27]) holding up to max_cold_blocks = 256 with cold_hit deduplication. Past 32k, oldest blocks invert RoPE (-ok_pos) and overflow into Attractors & M_res, locking state flat near 873 MB.

cold_cap ∈ {0, 16, 32, 64, 128, 256}  |  overflow: ok_kr = apply_rope_pos(ok_p, -ok_pos)
STAGE 06 • NEURAL CARTRIDGES & EXACT FORGET

Disk-Backed .vsa State Cartridges (0.0 Erase Residual)

Bolt3MemoryBank pre-encodes external documents into disk .vsa cartridges and routes queries by normalized embedding cosine similarity (37.44 ms avg route, 100% recall on 4/4 benchmarks). Because updates to M_res are linear delta traces, forget() subtracts gamma^k * delta with 0.0 algebraic residual.

states[li] ← states[li] - (gamma_delta ** n_res_steps) * delta  (res = 0.0)
