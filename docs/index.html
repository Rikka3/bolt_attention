STAGE 01 • THE MEMORY BOTTLENECK

Unbounded Softmax KV Grows Linearly Forever

Standard GQA Transformers like Qwen/Qwen3-4B append every new token's Key and Value across all 36 layers. At 65,536 tokens, exact bfloat16 KV caches consume 9,216 MB and memory-bandwidth saturation cuts decode throughput from 59.4 tok/s down to 29.6 tok/s.

KV_Bytes = L(36) * 2 * HKV(8) * HD(128) * T * 2B → 9.22 GB @ 64k
STAGE 02 • SINK + DOUBLE-BUFFERED LOCAL WINDOW

Chunked Execution (C = 128) & Unified CUDA Graph

Bolt-3 processes sequences in C = 128 token chunks. It permanently pins the first n_sinks = 4 tokens plus the previous and current chunks (2C = 256 exact local tokens). During single-token decode, _Bolt3GraphRunner writes into a single unified buffer updated in-place via index_copy_.

buf_k = [ sink(4) | ak_eff(128) | half0(128) | half1(128) | (cold) ]
STAGE 03 • DIVERSITY SOFTMAX ATTRACTORS

Branchless Cosine Merge & Novelty Eviction (S = 128)

When the older local chunk consolidates, keys matching an active attractor (cos_k ≥ 0.94 and cos_v ≥ 0.88) merge via weighted average, growing scalar mass (biasing scores by kappa * log(mass)) and mean RoPE position pm. Unmerged high-surprise tokens displace lowest-utility redundant slots (gamma_u = 0.985).

score_j = rel_err * (1 - best_sim_k)  |  keep_val = util * (1 - max_pair_cos)
STAGE 04 • GERSHGORIN RESIDUAL MEMORY

Bounded-Spectrum Delta Writes into M_res ([HKV, HD, HD])

Tokens that neither merge nor win an attractor slot write into a fixed [8, 128, 128] float32 matrix per layer. Row sums of |K K^T| compute a Gershgorin step bound so parallel chunk writes stay spectrally stable, decaying by gamma_delta and reading out through zero-initialized eta_proj + res_norm.

M_res ← gamma_eff * M_res + K_ev^T @ ((V - K_ev @ M_res) * beta / gershgorin)
STAGE 05 • OPTION-B SPARSE COLD-ARMED LAYERS

4 Mid-Deep Exact Buckets Capped Past 32,768 Tokens

In bolt3_b_qwen3_4b_latest.pth, 32 layers remain pure O(1) while 4 mid-deep layers ([14, 19, 24, 29]) retain exact Cold chunks up to max_cold_blocks = 256 in power-of-2 CUDA-Graph buckets. Past 32k, oldest Cold blocks invert RoPE (-ok_pos) and overflow smoothly into Attractors & M_res, locking state flat near 1.19 GB.

cold_cap ∈ {0, 16, 32, 64, 128, 256}  |  overflow: ok_kr = apply_rope_pos(ok_p, -ok_pos)
STAGE 06 • NEURAL CARTRIDGES & EXACT FORGET

Disk-Backed .vsa State Cartridges (0.0 Erase Residual)

Bolt3MemoryBank pre-encodes external documents into disk .vsa cartridges and routes queries by normalized embedding cosine similarity (37.44 ms avg route, 100% recall on 4/4 benchmarks). Because updates to M_res are linear delta traces, forget() subtracts gamma^k * delta with 0.0 algebraic residual.

states[li] ← states[li] - (gamma_delta ** n_res_steps) * delta  (res = 0.0)
